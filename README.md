One 1024×1024 image summing up the world's news of Tuesday 24 November 2026: 28 verified stories across 6 regions and 12 fields, each with its UTC time and source. `draw.py` renders the image offline with PIL at 3x supersampling (real system fonts, LANCZOS downsample to 1024); `main.py` (stdlib only) copies the pre-rendered `entry.png` byte-for-byte to the output directory and verifies the PNG signature and 1024×1024 size.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
